# Пансионат в Малаховке

[Открыть проект](https://stels935-arch.github.io/pansionat-malakhovka/)

Обновление 25 сентября 2026 года: на главной странице размещён интерактивный месячный калькулятор с настройкой мест, загрузки, стоимости проживания, аренды, всех штатных позиций и расходов. Результат пересчитывается при изменении полей.

Отдельные разделы: реальные фотографии объекта, обезличенные копии документов, бизнес-планы, финансовые модели, исследование, проверка здания и 3D-концепция.

Основа калькулятора — десятый месяц финансовой модели от 16 сентября 2026 года. Это отдельный пользовательский сценарий за месяц. Исходные документы и прогноз на 24 месяца сохраняются. Пользовательские значения хранятся в браузере, их можно скачать в CSV.

ГПЗУ и отдельный актуальный технический паспорт БТИ в предоставленных материалах не найдены. Листы «по планам БТИ» входят в архитектурный проект и не заменяют актуальную техническую инвентаризацию.

Для локального просмотра откройте index.html вместе со всеми соседними папками.
